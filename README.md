# Campus Pulse ??

**Campus Pulse** is a real-time campus crowd radar, seat telemetry, and mess velocity application delivered straight to your pocket. Stop guessing, start knowing.

## Features ?

- **?? Live Pulse Feed**: A real-time scrolling activity feed showing peer check-ins across campus.
- **?? Crowd Trend Graph (Sparklines)**: Subtle wave graphs on location cards indicating crowd changes over the last 6 hours.
- **??? Expandable Floor Selector & Predictors**: Tap on locations like the Library to see individual floor statuses, plus "Best Time" and "Avoid" time predictions.
- **?? Personal Profile**: Track your check-in history, maintain streaks, and unlock unique badges.
- **?? Gamification**: Earn points for checking into locations, climb the leaderboard, and become a Campus Legend.
